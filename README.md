# Quem é o culpado? Dota 2

Painel que julga uma partida de Dota 2: cole o ID da partida e veja o culpado, uma figurinha de
cada jogador do time, a linha do tempo, os momentos decisivos e o parecer de coach com itens
pensados contra o time inimigo.

**Acesse:** https://suetam016.github.io/culpado_dota2/

Os dados vêm da API pública do [OpenDota](https://www.opendota.com/), buscados direto do seu
navegador. Partida recém-jogada: o painel pede a análise do replay sozinho e recarrega quando
ficar pronta (de 1 a 10 minutos).

O código-fonte e os testes ficam no repositório privado do projeto; este repositório só publica
o arquivo gerado (`index.html`).
